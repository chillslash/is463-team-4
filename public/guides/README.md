# Static Reuse Guides

These are pre-made, category-level supporting infographics for staff outreach. They are not generated per partner and do not change the email-generation flow.

Category mapping:
- Schools / educational institutions
- Community gardens
- Farms / growers
- Landscaping / horticulture organisations
- Food-waste / material-recovery organisations

Parks, zoos and unmatched categories intentionally receive no automatic guide.
